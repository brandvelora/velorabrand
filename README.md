# VELORA — Wear Your Identity

Static fashion-brand website prepared for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `velora-website`).
2. Upload all files and folders in this project ZIP to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the website.

The site is plain HTML, CSS and JavaScript; no build step is needed.
The WhatsApp inquiry links use `+97466773235`. No email address is displayed.
Editorial images are local files in `assets/` (hero-1, tailoring, everyday, occasion, philosophy .jpg). Replace them with your own photos by changing the `url(...)` paths in `style.css`.
